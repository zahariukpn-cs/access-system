# access-system
ESP32-based smart locker system with RFID authentication, ESP-NOW Master-Slave wireless architecture, status feedback, and local Web Admin UI.

# Smart Locker System

**Автоматизована система керування доступом до комірок зберігання.**

Проєкт розробляється студентською командою з метою створення безпечного та зручного способу зберігання особистих речей. Система дозволяє програмно керувати електронними замками та в майбутньому підтримуватиме авторизацію користувачів.

## 🛠 Обладнання та компоненти (Hardware)

| Компонент | Модель / Опис | Кількість |
| :--- | :--- | :--- |
| **Мікроконтролер** | `[Наприклад: ESP32 / Arduino Uno / Raspberry Pi Pico]` | 1 шт. |
| **Замок** | Соліноїдний замок (12V) | 1 шт. |
| **Комутація** | Модуль реле (5V/12V) або MOSFET-транзистор (напр. IRF520) | 1 шт. |
| **Джерело живлення** | Блок живлення 12V (наприклад, 2A) | 1 шт. |
| **Захист** | Захисний діод 1N4007 (для гасіння індуктивних сплесків) | 1 шт. |

---

## 🔌 Схема підключення (Pinout)

| Пін мікроконтролера | Компонент | Опис |
| :--- | :--- | :--- |
| `GPIO 5` (або `D5`) | IN (Реле / MOSFET) | Сигнал керування (HIGH — відчинено, LOW — зачинено) |
| `GND` | Common GND | Спільна земля мікроконтролера та блоку живлення 12V |
| `5V` / `3.3V` | VCC | Живлення плати/модуля реле |

> ⚠️ **Важливо:** Переконайтеся, що мінус (GND) мікроконтролера та зовнішнього джерела живлення 12V з'єднані. Паралельно контактам соліноїда обов'язково встановлюйте зворотний діод.
