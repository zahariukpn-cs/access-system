# access-system
ESP32-based smart locker system with RFID authentication, ESP-NOW Master-Slave wireless architecture, status feedback, and local Web Admin UI.

# Smart Locker System

**Автоматизована система керування доступом до комірок зберігання.**

Проєкт розробляється студентською командою з метою створення безпечного та зручного способу зберігання студентських проєктів. Система дозволяє програмно керувати електронними замками, авторизувати користувачів.

## 🛠 Hardware

| Компонент | Модель / Опис | Кількість |
| :--- | :--- | :--- |
| **Мікроконтролер** | `[ESP32 ]` | 1 шт. |
| **Замок** | Соленоїдний замок (12V) | 1 шт. |
| **Комутація** | MOSFET-транзистор, 1кОм резистор | 1 шт. |
| **Джерело живлення** | Блок живлення 12V (наприклад, 0.5-2A) | 1 шт. |

---

## 🚀 Sofrware
Написана програма для відкриття закритого замка. Допоки замок закритий, транзитор отримує сигнал замикати коло замка. Коли замок відкривається, програма кожні 1000 мілісекунд перевіряє статус замка, доки той знову не буде закритим.
